# 📄 Professional Resume Studio

A lightweight, browser-based resume and CV builder designed to help job seekers quickly format, preview, and print clean professional resumes. Built as a fast, privacy-focused MVP using vanilla HTML5, CSS, and JavaScript.

## 🚀 Features

* **Live Preview:** See your resume format dynamically as you type your details.
* **Dynamic Sections:** Easily add, edit, or manage work experience and education background entries.
* **Print & PDF Export:** Cleanly formatted for browser printing and saving as a high-quality PDF.
* **Client-Side Storage:** All your data stays secure locally inside your browser session—no server storage or tracking.
* **Clean Layout:** Designed with a professional, ATS-friendly typographical hierarchy.
